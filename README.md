# ASCII Art with Python

Animated scenes made of glowing ASCII characters, rendered live with pygame-ce and numpy.

| Script | What it does |
|---|---|
| `bloom3d.py` | A 3D flower that blooms and spins |
| `skyline_sunrise.py` | A city skyline that goes from night to sunrise to morning, with a river reflection |

## Run
pip install -r requirements.txt
python bloom3d.py
python skyline_sunrise.py

Export a GIF: `python skyline_sunrise.py --gif sunrise.gif`
